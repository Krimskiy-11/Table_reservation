# Сайт для бронирования столиков в ресторане

Веб-приложение, предназначенное для онлайн-бронирования столиков в ресторане. Проект включает систему аутентификации пользователей, разграничение прав доступа для менеджеров и посетителей, а также полное тестовое покрытие бизнес-логики.

---

## Основной функционал

### Бронирование (`booking`)
* **Оформление брони:** Публичная форма создания бронирования (имя, телефон, дата, время, количество гостей).
* **Подтверждение:** Перенаправление на страницу с подтверждением после успешной отправки.
* **Управление бронями (для менеджеров):** 
  * Просмотр полного списка всех бронирований.
  * Редактирование параметров брони.
  * Удаление бронирований из базы данных.
* **Разграничение прав доступа:** Обычные пользователи и анонимные посетители не имеют доступа к менеджерскому интерфейсу (возврат ошибки `403 Forbidden`).

### Пользователи (`users`)
* **Регистрация:** Кастомная форма регистрации новых пользователей (`UserCreateForm`).
* **Аутентификация:** Вход/выход с использованием `email` в качестве логина.
* **Группы прав:** Поддержка группы `Managers` для разграничения доступа к административным функциям.

---

## Технологический стек

* **Язык программирования:** Python 3.14+
* **База данных:** PostgreSQL
* **Аутентификация:** Custom User Model (авторизация по `email`)
* **Тестирование:** Django Test Framework / `unittest`
